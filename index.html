Learn about passive radar

Passive radar detects objects using reflections from existing radio broadcasts. Read about how it works, what it can detect, and how to build a receiver.

The RETINA passive radar network

RETINA connects passive radar receivers operated at different locations. Each receiver compares a broadcast signal with its reflections to detect objects. The receivers send their observations to a shared map, where you can view aircraft tracks and network coverage.

Map preview · open for live data

View the network map

View receiver locations, aircraft tracks, and radar detections. The map includes ADS-B aircraft data for comparison, along with controls for coverage, detection arcs, and track history.

Node hardware

RETINA node kits

Each kit includes a Raspberry Pi, an RSPduo radio receiver, and a microSD card with the software installed. You will need to assemble the kit, connect antennas, and complete the radar setup before using it as a node on the network.

View kits and requirements →Assembly and radar setup required. Antennas and coaxial cables are not included.
